# MES NOTES ET SUIVIS

## Note du 8 janvier :

- **Mosquitto** semble servir de centre de tri de l'information mais, pas de stockage. C'est le docker.
- **PostgreSQL** (ma base de donnée) elle sert d'archive pour mettre l'information de façon permanente. 
- **Le Backend Python** s'occupe de faire la liaison entre les deux.
- **Le Docker** mets chaque partie dans des conteneurs avec tout le matériel nécessaire pour faire fonctionner le tout. 
- **Docker Compose** sert de plan de montage pour ces conteneurs.
